# FDV — сайт-визитка (морские контейнеры)

Статический сайт: HTML + CSS + немного JS, без сборщиков.

- `build.py` — генератор страниц. Меню, шапка, подвал, контакты и главная правятся здесь, затем: `python3 build.py`
- `css/style.css` — стили; цвета бренда в начале файла (`:root`)
- `img/logo.png` — логотип, `video/hero.mp4` — фоновое видео главной (Pexels, бесплатная лицензия)

Открыть локально: `open index.html`
